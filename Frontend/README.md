# Frontend

**Framework :** React + Tailwind CSS

Application cliente consommant les API exposées par l'API Gateway (`/api/...`). Trois espaces : Étudiant, Formateur, Administrateur.

## Démarrer en local

```bash
npm install
npm run dev
```

Configurer l'URL de la Gateway dans le fichier `.env` (`VITE_API_URL=http://localhost:8080`).
