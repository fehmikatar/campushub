# Enrollment Service

**Framework :** Django REST Framework
**Base de données :** PostgreSQL
**Port :** 8083

Gère les inscriptions des étudiants aux cours et le suivi de leur progression.

## Démarrer en local

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python manage.py runserver 8083
```
